# Avaritia Wallet

Wallet Dashboard  

> **Sunset:** this project is no longer maintained.

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Tech Stack

 - Framework: Next.js
 - Styling: Tailwind CSS
 - UI Components: shadcn-ui
 - Deployment: Vercel

## Local Setup

1. Clone the repo:

```bash
git@github.com:erujs/avaritia-wallet.git
cd avaritia-wallet
```

2. Install dependencies:

```bash
npm i
```

3. Run the development server:

```bash
npm run dev
```
